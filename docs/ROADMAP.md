# Roadmap

## Phase 1 — Foundation + Shell (tasks 000, 001)
Vite+React19+TS strict, Tailwind v4 tokens from DESIGN_SYSTEM.md, shadcn init, React Router data-mode skeleton, Storybook 10 (a11y + viewports), providers, MSW. **Layout config system + BOTH shell modes** (sidebar/topnav), single nav schema, command palette, theme/density toggles, layout switcher, mobile drawer/bottom nav.

## Phase 2 — Table + Forms (tasks 002, 003, 004)
Primitives + feedback; FormField+FieldHelp+sections+wizard; DataTable full contract vs mock API.

## Phase 3 — Domain modules (task 005+)
All ten: listings, users & agents, categories & attributes, locations, promotions & payments, messaging & complaints, reports & analytics, audit log, RBAC, settings/config. Listings first as the reference vertical.

## Phase 4 — AI-first layer
AssistantDock/Panel, NL filters (confirm-before-apply), three-tier moderation copilot, AI bulk actions, agent hooks + guardrails + audit `ai:<agent>`.

## Cross-phase always-on rules
Original design; mobile-first; AI-first; Storybook-first (incl. both modes for shell); FieldHelp; advanced tables; token-only; strict TS; user-only commits.
