# ADR 0002 — UI Foundation: shadcn/ui + TanStack
**Status:** Accepted
**Context:** Need owned, themeable components + powerful headless data primitives for an enterprise admin.
**Decision:** shadcn/ui (new-york, Radix/Base UI) themed with our OKLCH tokens; TanStack Query v5 (server state), Table v8 (NOT v9 beta), Virtual v3.
**Consequences:** Full control over markup/tokens; headless tables meet the 10-point contract; v8 chosen for stability (v9 still beta).
