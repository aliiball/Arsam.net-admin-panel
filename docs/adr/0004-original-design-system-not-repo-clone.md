# ADR 0004 — Original Design System (Not a Repo Clone)
**Status:** Accepted
**Context:** The previous scaffolding wrongly copied sahibinden-v2's visual identity (warm-paper cream/brown, Inter/Lora/JetBrains, liquid-glass dock). A copy-paste panel would be meaningless.
**Decision:** Design an ORIGINAL "Calm Signal" system (OKLCH slate + indigo/teal, Geist/Inter variable fonts, tabular numerals, subtle elevation, WCAG 2.2 AA, low-fatigue dark mode). sahibinden-v2 is retained ONLY as a component-TYPE reference, reinterpreted, never visually ported.
**Consequences:** Distinctive, professional identity suited to all-day use; explicit prohibition on old visuals; component ideas preserved without visual cloning.
